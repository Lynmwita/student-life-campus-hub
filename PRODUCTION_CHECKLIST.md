## 3. Security Verification & Isolation (Tiny 7c)
- [x] **Row-Level Security (RLS) Isolation:**
  - Student A cannot view or query Student B's tickets or personal preferences (0 rows returned).
- [x] **Locked-Door Sensitive Complaint Isolation:**
  - Sensitive complaints (`is_sensitive: true`) are visible ONLY to the filing student, the assigned staff member, and administrators.
  - Unassigned staff members receive 0 rows.
  - Other students receive 0 rows.
  - Every access is recorded in `audit_log`.
- [x] **Route Protection:**
  - Unauthenticated visitors attempting to reach `/dashboard`, `/timetable`, `/help-desk`, or `/admin` are redirected via middleware to `/login`.
  - Students accessing administrative modules are locked out with an `Access Restricted` state.
